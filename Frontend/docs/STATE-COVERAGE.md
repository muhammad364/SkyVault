## Shared control coverage

- Quiet Vault Select uses Radix keyboard navigation, typeahead, focus management, truncated values, internal scrolling, and viewport collision padding.
- Date and date-time pickers use a themed DayPicker calendar with keyboard navigation, exact min/max constraints, clear action, accessible labels, and an explicit local time field.
- Dropdown menus, popovers, dialogs, sheets, command surfaces, and filter cards use viewport caps, internal scrolling, safe-area spacing, `min-w-0`, and long-value containment.
- File, Search, Recycle Bin, Sharing, and Administration no longer use native application selects or native date/date-time inputs. Wire values are unchanged.
